# 微信公众号AI排版助手

一款专为微信公众号编辑优化的Chrome扩展，集成AI排版能力，支持HTML源码编辑、流式输出、智能清洗等功能，让排版工作更高效。

---

## 📦 安装方法

### 方法一：开发者模式加载（推荐）

1. **下载代码**
   ```bash
   git clone https://github.com/your-repo/wechat-editor-plugin.git
   cd wechat-editor-plugin
   npm install
   npm run build
   ```

2. **Chrome加载扩展**
   - 打开 Chrome，访问 `chrome://extensions/`
   - 开启右上角「开发者模式」
   - 点击「加载已解压的扩展程序」
   - 选择项目根目录（包含 `manifest.json` 的目录）

3. **验证安装**
   - 扩展图标应出现在浏览器右上角
   - 点击图标可打开设置页面

### 方法二：构建后加载

如果已获取构建好的文件：

1. 解压缩文件到任意目录
2. 按方法二步骤 2-3 加载扩展

## 🚀 使用流程

### 方式一：富文本模式（局部优化）

适用于对选中内容进行局部排版优化。

1. **打开公众号编辑页面**
   - 访问 `mp.weixin.qq.com/cgi-bin/appmsg`
   - 进入图文编辑界面

2. **选中内容**
   - 在编辑器中拖动鼠标选中需要优化的文字或段落
   - 侧边栏会自动显示选中的内容

3. **选择修改目标（可选）**
   - 选中文字后，侧边栏会显示「位置：xxx > xxx > xxx」
   - 这串标签表示你选中的文字在页面里的"层级位置"（类似俄罗斯套娃，从里到外）
   - **默认行为**：不点击任何标签，AI 只修改你选中的那行文字
   - **修改外层容器**：点击某个标签（如 `section.card`），AI 会修改整个卡片元素（如改背景色、加边框）
   - 点击后标签会高亮，可随时点「重置为选中内容」恢复默认

4. **输入需求**
   - 在侧边栏输入框中描述排版需求
   - 或选择预设提示词

5. **发送给AI**
   - 点击「开始 AI 排版」按钮
   - 等待流式输出完成

6. **查看结果**
   - 侧边栏显示AI生成的HTML
   - 内容自动应用到编辑器（无缝模式）
   - 或点击「确认并应用到编辑器」手动确认

### 方式二：HTML源码模式（全局优化）

适用于查看和编辑完整HTML源码，进行全局排版调整。

1. **进入源码模式**
   - 点击编辑器工具栏中的 **「切换HTML源码」** 按钮
   - 编辑器切换为HTML代码编辑界面
   - 侧边栏自动同步显示当前HTML

2. **编辑或输入需求**
   - 可直接在编辑器中修改HTML代码
   - 或在侧边栏输入AI优化需求

3. **AI优化**
   - 在侧边栏输入排版需求
   - 点击「开始 AI 排版」

4. **退出源码模式**
   - 点击 **「退出源码模式」** 恢复富文本编辑
   - 修改后的HTML自动应用到编辑器

## ✨ 功能特性

### 1. 双模式编辑

| 模式 | 适用场景 | 特点 |
|------|----------|------|
| **富文本模式** | 局部内容优化 | 所见即所得，选中即处理 |
| **HTML源码模式** | 全局结构调整 | 查看完整HTML，精准控制 |

### 2. 智能清洗

- **自动去除解释文字**：AI返回的思考过程、说明文字会被自动过滤
- **Markdown代码块去除**：自动去除 ```html 等标记
- **标签内解释清除**：智能识别并清除HTML标签间的中文解释

### 3. 流式输出

- **实时预览**：AI生成内容实时显示
- **动态清洗**：流式过程中实时过滤无关内容
- **进度可见**：无需等待，边生成边查看

### 4. 编辑模式

- **无缝编辑模式**：AI结果自动应用到编辑器，适合熟练用户
- **手动确认模式**：生成后预览，确认后再应用，适合精细控制

### 5. 预设提示词

内置常用排版预设，一键使用：

- 优化移动端排版
- 增加卡片样式
- 简化代码

### 6. 选区标记

- **精确替换**：使用标记在源码中精确定位选区
- **智能上下文**：自动携带选区前后文，确保AI理解完整语境

### 7. ProseMirror兼容

- 完美适配微信公众号的ProseMirror编辑器
- 使用标准DOM操作，确保编辑器状态同步

## 🐛 常见问题

**Q: AI返回了代码块标记怎么办？**  
A: 插件会自动清洗去除 ```html 等标记，无需手动处理。

**Q: 为什么有时候AI会输出解释文字？**  
A: 插件已有多层防护（提示词限制 + 实时清洗 + 最终清洗），但偶尔仍可能出现。如遇此情况，重新发送请求即可。

**Q: 如何重置设置？**  
A: 在设置页面点击「重置」按钮，或在扩展管理中清除存储数据。

**Q: 支持哪些AI模型？**  
A: 本插件支持Anthropic接口和OpenAI兼容接口的模型，包括Claude、Kimi code、GPT等。

**Q: 侧边栏显示的「位置：xxx > xxx」是什么意思？**  
A: 这表示你选中的文字在页面里的"嵌套层级"，就像俄罗斯套娃一样——最左边是最里面的小娃娃（你选中的文字本身），越往右是越大的盒子。

常见标签的通俗含义：

| 标签名 | 通俗理解 | 什么时候点它 |
|--------|----------|--------------|
| `span` / `strong` / `em` | 文字本身的样式（加粗、斜体、颜色） | 只想改几个字的颜色或大小时 |
| `p` | 一个段落 | 想改整段文字的排版时 |
| `section` / `div` | 一个"卡片"或"区块"（通常有背景色、边框、圆角） | **想改卡片背景色、加阴影、改边框时选这个** |
| `article` / `body` | 更大的内容区 | 想改整篇文章的底色时 |
| `div.ProseMirror` | 微信编辑器本身 | 一般不需要点这个 |

如果不确定，**先不点任何标签**（默认只改文字），如果 AI 没有改到你想改的地方，再回来点外层的 `section` 或 `div` 试试。

**Q: 我想改卡片的背景色，但 AI 只改了文字颜色怎么办？**  
A: 这说明你选中的只是"文字"，AI 只能修改文字。请重新选中卡片里的文字，然后在侧边栏点击位置标签里最外层的 `section` 或 `div`（带有 `.card` 或类似类名的那一项），再发送需求，AI 就会修改整个卡片了。
